# Около балкона (okolo-balkona)
Лендинг: остекление, утепление, отделка балконов и лоджий, СПб. Ref формы: GLNTZGRGEZ.
Идея: холодный -> тёплый. Hero с тремя состояниями окна, закреплённая 3D-сцена «пирог утепления» (CSS 3D, прогресс скролла), калькулятор «от», лестница цен.
Заглушки: название «Около балкона» (из домена), формулировки про два этапа, замер, зону работ. Телефона нет: контакт через форму и VK.
